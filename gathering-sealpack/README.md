# 地精采集系统

SealDice JS 扩展，提供蘑菇与浆果采集玩法，并直接写入地精背包核心的共享个人变量。

## 指令

- `.采集`：开始采集，发送提示后等待 2 秒抽取一种素材。
- `.采集信息`：查看采集规则与稀有度概率。
- `.采集图鉴`：查看全部素材。
- `.采集图鉴 蘑菇`：查看蘑菇图鉴。
- `.采集图鉴 浆果`：查看浆果图鉴。

## 稀有度

- 普通：70%
- 少见：24%
- 稀有：6%

## 背包接入

采集物直接写入海豹个人变量 `$m地精背包数据`：
- 蘑菇写入 `items.mushroom`
- 浆果写入 `items.berry`

请先安装并启用「地精背包核心」。采集物会与钓鱼系统的鱼类及其他背包物资共享，不另建背包。

## 有毒素材

「红菇属」标记为有毒类。获得时不会自动扣血；若玩家通过背包核心的食用机制食用，则按核心中已配置的效果扣除 1 HP。该效果仅为游戏设定，不构成现实食用建议。
