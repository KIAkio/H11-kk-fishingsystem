# 冬训营生活系统 v1.0.2

## 指令
- `.点名`：北京时间 00:00—11:59 每日一次；仅限已注册用户，跨群共享签到记录。
- `.点名信息`：查看个人累计点名次数。
- `.点名排行`：查看当前群已记录的累计点名排行。
- `.食用 食物名称`：食用背包中的已配置食物，HP +1；营地早餐饱腹 +3。
- `.共享 食物名称 @同学...`：自己加 1—3 位被 @ 同学，总人数 2—4 人；每人 HP +1，恰好两人时每人饱腹 +1。
- `.饱腹`：查看饱腹值及【饥饿】状态。
- `.营地菜单`：查看 11 种早餐。

## 规则
- 点名记录存入个人变量 `$m冬训营点名数据`，跨群共用。
- 早餐写入共享背包变量 `$m地精背包数据` 的 `items.other`。
- 每份早餐恢复饱腹 3、HP 1；饱腹上限 4。
- 双份早餐概率 10%，双份只显示名称。
- 早餐在次日北京时间 08:00 过期；到期后在玩家下一次触发生活系统指令时清理。
- 饱腹在北京时间 05:00 重置为 1，10:00、15:00、20:00 各扣 1。
- 离线期间的饱腹时间节点在玩家下一次触发生活系统指令时补算。
- `.状态` 由地精背包核心统一显示 HP、饱腹值和【饥饿】，避免重复注册同名指令。
