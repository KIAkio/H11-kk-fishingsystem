# 冬训营生活系统 v1.0.0

## 指令
- `.点名`：北京时间 00:00-11:59 每日一次；仅限已注册用户。
- `.点名信息`：查看个人累计点名次数。
- `.饱腹`：查看饱腹值及饥饿状态。
- `.营地菜单`：查看 11 种早餐。

## 规则
- 点名记录存入个人变量 `$m冬训营点名数据`，跨群共用。
- 早餐写入共享背包变量 `$m地精背包数据` 的 `items.other`。
- 每份早餐恢复饱腹 3、HP 1；饱腹上限 4。
- 双份早餐概率 10%，双份只显示名称。
- 早餐在次日北京时间 08:00 过期。
- 饱腹在北京时间 05:00 重置为 1，10:00、15:00、20:00 各扣 1。
- 离线时间在玩家下一次使用本插件指令时补算；过期早餐也在下一次触发时清理。
