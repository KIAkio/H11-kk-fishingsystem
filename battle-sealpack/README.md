# 圣布里吉冬训营战斗系统 0.2.0

在海豹核心 1.6.0 或更高版本的「扩展包」页面导入本包，并启用已完成营地档案统一的地精背包核心 1.8.5。队群里可发 `.ext winter_camp_battle on` 启用战斗指令。安装后用 `。战斗 帮助` 检查；若中文前缀未响应，可用 `.战斗 帮助`，或在海豹设置中加入中文句号 `。` 和逗号 `，`。

## 录入角色与护甲

在小窗或队群发送 `。录入 速度60，灵敏65，洞察50，攻击70，防御40`，保存到发送者当前的营地角色。五项都须填写 0–100 的整数，顺序可调整。切换营地角色后再录入，会保存到对应编号。用 `。战斗 档案` 核对属性、营地 HP 和装备护甲上限。重新组队会自动读取，已开战的队伍在下一场遭遇应用新属性。

护甲由角色穿戴的训练装备计算。未穿戴时为 0，同名装备只能穿戴一次，总上限为 8。骰主可用 `。战斗 护甲装备 3 防寒背心` 为装备登记护甲值，由营地发放训练装备。角色领取后用 `。战斗 穿戴 防寒背心` 或 `。战斗 脱下 防寒背心` 管理穿戴。战报把当前护甲及上限跟 HP 放在同一行。护甲归零后隐藏，超出的伤害扣 HP。下一场遭遇会重新核对装备库存及容量，并沿用已有的损耗。

## 开一场冰狼遭遇

1. 由队群管理员、群主或骰主发 `。战斗 开队`。
2. 队员在群里各发 `。战斗 加入`，使用当前角色。可附上本人名下的编号，例如 `。战斗 加入 005`。
3. 由开队者或骰主在群里发 `。战斗 开始`。小队最多 10 人。各群有独立战斗，每个 QQ 账号同一时间加入一个小队。
4. 轮到自己时，可在队群或机器人小窗提交动作。小窗会回执，结果发回队群。用 `。战斗 状态` 查看顺序、血量及护甲。

| 场景 | 指令 |
| --- | --- |
| 简单攻击 | `。战斗 攻击` → `。战斗 直接` |
| 解析破绽 | `。战斗 解析` → `。战斗 自析` 或 `。战斗 求助` |
| 怪物攻向你 | `。战斗 格挡` 或 `。战斗 闪避`，可在末尾加「求助」 |
| 为当前动作喊话 | 按战报给出的码发 `。战斗 喊话 行动码` |
| 结束喊话等待 | 当事人或带队按战报发 `。战斗 结算 行动码` |
| 跳过当前行动 | `。战斗 跳过`，带队可代为处理。遇袭等待时会按格挡处理 |
| 投掷物品 | `。投掷 雪球`，仅当前出手者可用 |
| 整备治疗 | `。战斗 治疗 005` |
| 收队 | 带队在小队群发 `。战斗 收队` |

## 试玩规则

- 速度高者先行动，怪物也在顺序中；同速按加入顺序。伤害先扣护甲，再扣 HP，护甲耗尽后从战报隐藏。
- 每次求助接收一次喊话，队友先做洞察检定，成功按当前动作增加命中、格挡减伤或闪避门槛。喊话后会立即结算，迟到的相同行动码不会消耗次数。
- 普通伤害为 2 加攻击每满 20 点提供的 1 点，防御每满 20 点减少 1 点。格挡额外减伤 2 点。闪避成功令敌人命中率下降 20 个百分点。洞察成功后，攻击或闪避检定增加 10 个百分点，格挡额外再减伤 1 点。
- 每位队员每轮最多喊话一次。默认喊话一次后冷却一整轮。冷却及可连续使用的次数可以在集结时调整。
- 投掷、闪避、攻击及洞察使用 d100，骰值低于或等于相应的成功率时通过。投掷成功固定造成 2 点伤害，按普通伤害扣护甲及 HP。物品名由玩家输入，试玩期间无需从营地背包扣除物品。
- 击败怪物才进入整备。每位仍可行动的队员可治疗一次，回复目标最多 3 HP，可救起倒下的队友。带队可再发「开始」，沿用本队 HP 和剩余护甲。
- 入队时读取营地角色 HP。此版本的伤害与整备治疗保存于战斗小队，营地食用、点名等仍使用原营地 HP。

### 带队调整

- `。战斗 喊话设置 005 2 1`，依次为小队角色编号、连续喊话次数、冷却轮数。
- `。战斗 开始 冰狼 16 2 40 55 20`，依次为怪名、HP、护甲、速度、攻击、防御。
- `。战斗 移除 005`，集结阶段可移除指定队员。
