# 地精背包核心

SealDice JS 扩展，为钓鱼、地精采集和冬训营物资分发提供统一的玩家背包数据。

## 当前指令
- `.注册 姓名`：建立档案并登记显示名称；不填姓名时使用平台昵称
- 重复执行 `.注册 新姓名` 可更新登记姓名
- 小蜘蛛彩蛋仅在成功执行 `.重置所有背包 确认` 后出现
- 档案显示已修复换行，BUGx1 小蜘蛛彩蛋保留在 `.注册` 档案末尾
- `.注册`：建立档案，群内编号从 000 起独立递增
- `.重置所有背包 确认`：清空自己跨群共享的全部背包物品并恢复 HP；不会删除群内档案编号
- `.发放 @玩家 分类 物品名 数量`：管理员向指定玩家发放物品（需管理员以上权限）
- `.背包`：查看全部物品
- `.背包 鱼类`：查看鱼类
- `.背包 蘑菇`：查看蘑菇
- `.背包 浆果`：查看浆果
- `.背包 日用品`：查看日用品
- `.背包 训练装备`：查看训练装备
- `.背包 其他`：查看其他物品
- `.状态`：查看 HP
- `.食用 物品名`：食用已配置效果的物品
- `.丢弃 物品名 数量`：丢弃指定数量；数量可填“全部”

背包标题会自动使用玩家当前名称，例如“某某的背包”。

## 档案与背包范围
- 档案编号按群独立分配，每个群从 `000` 开始递增。
- 背包物品与 HP 保存在个人变量中，同一账号跨群共享。
- 档案展示保留彩蛋：`BUGx1：一只小蜘蛛....你怎么在这儿？`

## 统一存档接口
玩家数据保存在海豹个人变量 `$m地精背包数据` 中，便于其他扩展读取并写回。

分类键为 `fish`、`mushroom`、`berry`、`supplies`、`equipment`、`other`。

每个物品条目可包含：
```json
{
  "count": 1,
  "description": "物品描述",
  "consumable": false,
  "durability": 100,
  "equipped": false
}
```

- `consumable: true` 表示消耗品。
- `consumable: false` 表示可重复使用物品。
- `durability` 用于可记录耐久度的装备。
- `equipped` 用于标记装备状态。

## 说明
- 每位玩家独立存档；同一玩家在不同群聊中共享个人背包。
- 鱼类、蘑菇、浆果和装备由对应玩法或分发模块发放，不会自动生成。
- 止血带、折叠刀、望远镜等仅作为虚构冬训营游戏物资条目记录；本扩展不提供现实医疗或武器使用指导。
- 当前版本暂不实现物资分发指令，后续单独开发并接入本背包核心。
